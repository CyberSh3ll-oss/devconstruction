🟢 INPUT LAYER
Feature	Description
📅 Smart Date Picker	Native date input, auto-defaults to today. Formatted as DD/MM/YYYY on the bill.
📝 Dynamic Item Rows	Add up to 8 line items per bill. Each row = description + amount. Remove individual rows on the fly.
🔒 Live Validation	Blocks download if date is missing, if no items exist, or if any row is half-filled.
🔵 PROCESSING LAYER
Feature	Description
🧮 Auto-Total Calculator	Indian-format currency (en-IN locale) with comma grouping — 53,000/- style.
📐 Canvas Text Fitting	Every piece of text is dynamically sized to fit its target width — no overflow, no ugly wrapping, ever.
🎨 Custom Letter-Spacing	Pixel-perfect kerning engine for the company name and headers.
🟢 OUTPUT LAYER
Feature	Description
🖼️ JPEG Bill Export	canvas.toBlob() → auto-downloads Bill_DD-MM-YYYY.jpg at 1204 × 1600 px, print-ready.
👁️ Live Preview	Real-time canvas mirror of the final bill — updates on every keystroke.
✍️ Signature Embed	Base64-encoded PNG signature baked straight into the bill.
🟡 QUALITY-OF-LIFE
Feature	Description
♿ Accessibility	Semantic labels, role="status" live regions, high-contrast :focus-visible outlines.
📱 Responsive Layout	CSS Grid — single column on mobile, two-column (form + sticky preview) on desktop ≥ 900 px.
🖨️ Typography	EB Garamond loaded via Google Fonts with graceful fallbacks for offline use.
